# APG Landscape Downloads

[Download the latest setup](https://github.com/mohamednawara1995-oss/APG-Landscape-Downloads/releases/latest/download/APGLandscapeSetup.exe)

Official compiled installer and update packages for Revit 2024 and 2025. No GitHub account or token is needed to download or check this public update feed.

Save your work, close Revit, run APGLandscapeSetup.exe and select 2024, 2025 or both. Reopen Revit. APG Landscape includes Check for Updates and Update Settings.

Existing private-feed or local trial installations: install this public setup once. It sets the update repository to mohamednawara1995-oss/APG-Landscape-Downloads. Leave the optional private-repository token blank for fresh installs.

Plugin source files are not distributed here. GitHub's automatically labelled “Source code” archives contain only this distribution repository's files.
